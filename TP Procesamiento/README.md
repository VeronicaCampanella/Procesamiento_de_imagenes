TP Procesamiento digital de imágenes

Librerias necesarias:
- numpy
- Pillow

Archivos:
- main.jpg: Imagen que usa Main.py
- brillo.jpg: Imagen que usa Brillo.py
- contorno.jpg: Imagen que usa Contorno.py
- desenfoqueJPG.jpg: Imagen que usa Desenfoque.py
Carpeta "TP Procesamiento":
- Main.py: Script principal que carga una imagen y ejecuta las funciones de los demas archivos
- Brillo.py: Función para aumentar brillo
- Contorno.py: Función para resaltar contornos
- Desenfoque.py: Función para aplicar desenfoque


Uso:
- Cambiar las rutas de las imagenes antes de correr los archivos
- Al correr el script Brillo.py se mostrara la imagen brillo.jpg con el aumento de brillo aplicado (es posible modificar la intensidad del brillo)
- Al correr el script Desenfoque.py se mostrara la imagen desenfoqueJPG.jpg con el desenfoque aplicado (es posible modificar el radio del enfoque para hacerlo mas intenso o mas tenue)
- Al correr el script Contorno.py se mostrara la imagen contorno.jpg con el filtro de CONTOUR aplicado
- Al correr el script Main.py se mostrara la imagen main.jpg con las tres funciones aplicadas
